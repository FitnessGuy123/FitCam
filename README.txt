FITCAM PRO — PHONE SETUP

1. Extract this folder.
2. Do NOT open index.html directly from Downloads if you want camera access.
3. Put the folder on a static HTTPS host (for example GitHub Pages, Cloudflare Pages, Netlify, or another HTTPS static host).
4. Open the HTTPS site on Android Chrome.
5. Allow camera permission.
6. Pick an exercise -> target -> Start AI workout.
7. Put the whole body in frame, use good lighting, and keep the phone stable.

IMPORTANT
- The app uses MediaPipe Pose Landmarker in the browser. Google documents live-stream/video pose detection and a single-person pose option.
- The app is a rep-estimation tool, not a medical device or a guarantee of perfect form.
- Camera access is controlled by the browser and normally requires a secure context (HTTPS/localhost).
- AI files are downloaded when the app first loads, so the first start can take longer.

EXERCISES
Push-ups, squats, reverse lunges, glute bridges, bird-dogs, dead bugs, side plank, plank, jumping jacks, high knees, mountain climbers, wall sit, crunches, sit-ups, calf raises, arm raises, side bends, toe touches.
